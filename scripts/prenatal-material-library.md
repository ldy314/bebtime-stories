# 胎教期材料库 ·「故事孕育师」方法（可读版）

> 本文件是每日胎教期故事的**常驻材料库**与**生成方法**的人话版本。
> 权威实现（被生成脚本实际读取）在 GitHub 仓库 `scripts/prompt-builder.js`：
> `PRENATAL_CAST` / `PRENATAL_SCENES` / `PRENATAL_IMAGERY` / `EMOTIONAL_ANCHORS` /
> `PRENATAL_SAFETY` 与 `buildPrenatalBlock()`。两者必须保持一致——改了代码就以代码为准，
> 改了这里也要同步回代码。
>
> 生效范围：**仅胎教期（2026-09-22 之前）**。日期进入 0-1 岁当天起，这套增强不再注入。
> 与「黑猫当当历险记」系列**完全分离**：当当是独立周更系列，不混入每日故事。

---

## 一、核心思路（故事孕育师）

把每篇胎教故事当成「在妈妈肚子里为还没到来的宝宝轻轻讲的一个小世界」：

- 世界必须**全然善意与安全**，没有任何危险、冲突、失落。
- 用「常驻小主角 + 温柔连续感」替代每天从零起号的随机感，让宝宝慢慢熟悉几个声音。
- 每篇至少自然嵌入 **3 个情感锚点**，把「爱、守护、等待」织进画面里。
- **固定的情感高光**：让主角途经温暖水域/光晕，感知到「妈妈的心跳」——这是所有胎教故事共同的温柔落点。
- 结尾一律是温柔守候，对宝宝说「等你准备好了，外面的世界有软软的风和圆圆的月亮等你」。

## 二、常驻角色库（Prenatal Cast）

每日胎教故事优先用一位「小主角」，以其设定为基准展开，保持性格与口头禅前后一致。
同一篇里可让它遇见库里其他伙伴，形成温柔的连续感。

| 主角 | 类型 | 家 | 性格 | 口头禅 |
|------|------|----|------|--------|
| 小海螺·小旋旋 | 白海螺 | 深海海草森林 | 安静、温柔、好奇 | 原来是这样呀…… |
| 月亮妈妈 | 守护者 | 夜空 | 温柔、守护、智慧 | 安心睡吧，妈妈在呢。 |
| 小星星·暖暖 | 暖黄小星星 | 夜空 | 圆滚滚、爱眨眼睛、爱陪伴 | 我陪着你呀。 |
| 小熊·安安 | 小棕熊 | 森林树洞 | 软软的、慢吞吞、有安全感 | 呼……噜…… |
| 露珠邮递员·露露 | 小露珠 | 清晨花瓣 | 活泼、爱问问题 | 有信来啦！ |
| 云朵精灵·朵朵 | 云端小精灵 | 云端棉田 | 轻盈、爱照顾人 | 飘呀飘，到家啦。 |
| 小种子·芽芽 | 小种子 | 妈妈的花园 | 耐心、满怀希望 | 再等等，就快了。 |
| 小鸟·啾啾 | 小鸟 | 屋檐 | 会唱摇篮曲、温柔 | 啾啾，睡吧。 |
| 小闹钟·叮当 | 小闹钟 | 窗台 | 爱学唱歌、准时不闹 | 叮咚，该睡啦。 |

**确定性分配**：主角 = `hashDate(日期 + '-prot-' + 语言) % 9`。
英文再偏移半个库（`+4` 再取模），保证同一天中文与英文主角不同、但都稳定可复现。

> 已有故事的主人公就是最珍贵的素材。例如小海螺·小旋旋出自用户亲手创作并收录的
> 《小海螺的第一次远行》——它已被纳入常驻库，可在不同故事里让它偶尔与其他伙伴相遇。

## 三、场景与意象

- **场景**：海草森林、月光海面、云端棉田、妈妈的花园、星夜天台、暖暖被窝
- **意象**：星星灯笼、心跳小鼓、梦的种子、云朵口袋、月光小船

这些场景/意象可顺带出现，让每日的小世界彼此呼应、更有连贯感。

---

## 四、情感锚点（每篇至少嵌入 3 种，多选多益）

1. **心跳/节拍**：妈妈的心跳、血脉流动声、钟摆声（固定高光：让主角感知「妈妈的心跳/微光」）。
2. **包裹/承载**：柔软云墙、气泡、被水流/风轻轻托着、温暖的被窝——暗合羊水里的被包裹感。
3. **光与希望**：微光、星光、萤火、黎明的金边。
4. **温度与触觉**：手掌温度、温牛奶热气、阳光暖照、软软的毛茸茸。
5. **声音记忆**：爸爸的笑声、妈妈的哼歌、门铃、拖鞋声。
6. **成长意象**：种子发芽、小脚印、房子变大、宝宝安心长大。
7. **家庭连结**：哥哥的画、奶奶的袜子、全家声景、妈妈的声音。

## 五、安全边界（绝对遵守）

- 禁止任何危险、冲突、跌落、破碎、黑暗吞噬、分离、追赶情节。
- 禁止否定式安慰（如「不要怕」「别哭」），只用正向温柔的安抚。
- 禁止角色有不幸经历或负面性格；世界必须全然的善意与安全。
- 胎教故事讲给肚里尚未出生的宝宝听：**绝不可把宝宝写成已经出生**；结尾多以
  「等你准备好了」「安心长大就好」等温柔守候收束；可让主角途经温暖水域/光晕，
  感知到「妈妈的心跳」作为固定的情感高光。
- **项目硬约束**：禁止出现螃蟹 / 大闸蟹 / 任何蟹类角色、食物或情节（含长荡湖等以蟹为卖点的内容）。
- 不使用中文弯引号「"」，用「」或单引号（否则 stories.json 解析失败）。

## 六、故事骨架提示

```
微小主角
  → 一个温柔的愿望
  → 被水流 / 风 / 歌声轻轻托送（暗合羊水体验）
  → 遇见颜色 / 味道 / 温度 / 旋律的感官之美
  → 途经温暖水域或光晕，感知到「妈妈的心跳」作为固定高光
  → 用「小宝宝，你听到了吗？」式对话与肚里宝宝说话
  → 以温柔守候收尾（如「等你准备好了，外面的世界有软软的风和圆圆的月亮等你」）
```

## 七、如何扩展这个库

- **加角色**：往 `prompt-builder.js` 的 `PRENATAL_CAST` 增一项（含 `name/en/type/enType/home/enHome/personality/enPersonality/catchphrase/enCatchphrase`），
  并在本文件第二节表格同步加一行。`PRENATAL_CAST.length` 变了会自动影响主角轮换周期与英文偏移（`Math.floor(len/2)`）。
- **加场景/意象**：在 `PRENATAL_SCENES` / `PRENATAL_IMAGERY`（及 EN 版）增项，并在第三节同步。
- **加/调情感锚点**：改 `EMOTIONAL_ANCHORS`（及 EN 版），并在第四节同步；锚点数量变化不影响逻辑（渲染时自动编号）。
- **改安全边界**：改 `PRENATAL_SAFETY`（及 EN 版），并在第五节同步。务必保留「无蟹」「未出生」「无弯引号」三条硬约束。
- 任何修改后跑一遍 `node --check scripts/prompt-builder.js` 与渲染自测（见仓库内测试脚本），确认 prenatal 注入、post-birth 不注入、无语法错误。

## H5 阅读器新增年/月筛选（用户要求）
- 需求：故事显示可按「年/月」筛选，默认显示当前月份。
- 实现（bedtime-story-app/index.html，同步 4 副本）：
  - header 新增 `.month-switch` 行，含 yearSelect/monthSelect 两个下拉框 + 样式。
  - 状态变量 currentYearFilter/currentMonthFilter（默认 'all'），`defaultToCurrentMonth()` 在 init 时定位到本地当前年月（2026-08）。
  - `storyYearMonth(s)`：优先从 id 提取（`2026-08-14-cn`），兜底从 date 字段（`2026年8月15日`）提取——**关键**：当当系列 id 是 `dangdang-ep22-zh` 无日期，必须靠 date 兜底，否则系列故事在年月筛选下丢失。

  - renderStoryList 中年月过滤作用于所有类型（每日/系列/科学），位于系列/年龄/语言过滤之后。
  - yearSelect change 时重建月份选项（保持当前月或回退 all）。

# 00 · 权威源文件（Canonical Sources）

本文件夹存放「黑猫当当历险记」系列**全部已整理素材的权威副本**，从项目根目录同步**拷贝**（非移动），保证 `storyline\` 素材库可独立查阅、不依赖线上运行目录。

> **同步纪律**：根目录源文件更新后，应覆盖此处对应副本，并据其重新生成各分类文件夹中的「视图文件」。单一事实来源始终是本文件夹 + 根目录运行文件，各分类文件夹为组织化视图，避免多处手改导致漂移。

| 文件 | 性质 | 说明 |

| `dangdang-series-outline.md` | 剧情档案 | ep01–ep19 分集大纲 + 跨集伏笔 + 待生成参考 |

| `dangdang-series-state.json` | 连续性状态 | episode/arc/continuity/linkages，自动生成读取 |

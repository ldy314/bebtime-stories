## 硬约束（与旧模板冲突时以本库为准）
- **白猫姐姐 = 小不点**（家中）；安徽定远那只白猫正式定名 **卡莎**，正文禁止写「白猫姐姐」。
- 格格巫身边**没有阿兹猫**（避免与猫咪角色冲突）。
- 反派全部低龄友好：只偷窃/捣乱/恶作剧，无暴力、不被伤害。

## 出场规则
- 当当每集必出，是核心视角；其余角色按剧情需要出场，不必每集到齐。
- 允许「当当 + 1 配角」小场景；无论谁出场都要落「连续性弧线」与「教育点」。
- 反派按「伏笔—再现—收线」跨集编排，不必每集正面登场。

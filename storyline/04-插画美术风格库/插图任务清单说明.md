# 插图任务清单说明

> 本文件说明插图模块的产物结构，便于后续手动出图或自动化消费。

## 产物文件（根目录，已被复制到 `00-权威源文件`）
- `illustration_jobs.json`：任务清单，结构为 `{"out_dir":..., "note":..., "jobs":[...]}`。`jobs` 每项含 `title / style_key / style_name / prompt / out_path / done`。
- `illustration_assignments.json`：风格分配持久化（标题→风格key），catalog 改动不破坏已生成图风格标注。
- `illustration_generation_queue.jsonl`：`--generate --backend workbuddy` 时产出，供 image-creator 用 ImageGen 出图。

## 消费方式
1. 读 `illustration_jobs.json`，筛 `done == false` 的任务。
2. 用其 `prompt` 调用图像工具（HY-Image-V3.0 / ImageGen）出图，保存到 `out_path`。
3. 出图后脚本按文件存在自动标 `done`，无需手改。

## 与故事库的关系
- 插图与 `stories.json` 一一对应（按 `title` 匹配）；新增故事由 `apply_series_episode.py` 写入后，重跑生成脚本即可纳入轮转。

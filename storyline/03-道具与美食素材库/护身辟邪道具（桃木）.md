# 护身辟邪道具（桃木）

> 家中护身小物，由**爸爸妈妈亲手**为猫咪们准备，呼应「保护宝宝」家规。写文 / 出图时作为家庭设定保持一致。
> 权威源：`series-dangdang-guide.md` 二·E 节。

## 分工（谁做什么）
- **爸爸负责雕刻**：所有桃木 / 桃核部件（剑、人、刀、篮、鱼、扣、笔）都由爸爸用刻刀手工雕成。
- **妈妈负责编绳**：雕好的部件由妈妈穿上编绳、打结，做成可佩戴的挂饰 / 项圈坠，系在猫咪脖子或挂在宝宝身边。

## 三只猫（当当 / 小不点 / 八百）每人一份
| 道具 | 形态 | 寓意 | 佩戴位置 |
|------|------|------|----------|
| 小桃蓝（桃木小挂饰 / 小桃篮） | 桃木雕刻的小挂篮 | 安放小物、象征被好好照料 | 项圈挂坠 |
| 桃木剑 | 迷你桃木小剑 | 传统辟邪，守护平安 | 项圈挂坠 |
| 平安扣 | 桃木圆扣（妈妈编绳穿孔） | 平安顺遂 | 项圈挂坠 |

## 宝宝额外一份（更多守护）
| 道具 | 形态 | 寓意 | 摆放 / 佩戴 |
|------|------|------|-------------|
| 桃木人 | 桃木小娃娃 | 替身护佑、陪伴宝宝 | 宝宝床边 / 推车挂件 |
| 桃木刀 | 迷你桃木小刀 | 辟邪守护（与桃木剑呼应，宝宝专属） | 宝宝床边 |
| 文昌笔 | 桃木小笔 | 聪慧好学、茁壮成长 | 宝宝床边 |
| 桃核鱼 | 桃核雕的小鱼 | 年年有余、活泼灵动 | 宝宝推车挂件 |
| 桃核福袋 | 桃核雕的小福袋 | 福气满满、安稳吉祥 | 宝宝床边 |

## 出图 / 写文一致性要点
- **桃木材质**：暖黄木色、表面有细刻痕；桃核雕件（鱼 / 福袋）带天然核桃纹路、颜色略深。
- **编绳配色**：妈妈编绳多为浅色棉绳（米白 / 浅粉 / 浅蓝），与当当浅蓝领结、小不点粉丝带色系统一。
- **反派禁用**：一只耳 / 格格巫绝不佩戴这类护身物。
- **温情用法**：可作为「家规 = 保护宝宝」的注脚——如睡前爸爸刻好一件、妈妈编好绳，给每只猫 / 宝宝一一戴上；宝宝那份（桃木人 / 刀 / 文昌笔 / 桃核鱼 / 福袋）更显「被全家守护」。
- **分龄提示**：胎教期 / 0–1 岁前半段可只描写「挂饰静静躺在宝宝枕边」的画面氛围；宝宝大些后才在情节里点出爸爸雕刻、妈妈编绳的亲子过程。

# 06 · 创作灵感素材库

> 碎片化创意收集与拼接灵感，写新集前在此取用，避免每次从零构思。

## 文件
| 文件 | 内容 |
|------|------|
| `主题立意库.md` | 12 个正向主题方向（保护家人/打击坏蛋/旅游爬山/古迹/龙宫/格格巫/美食/助人/做客/地域旅行/奇妙朋友/环球双语连线） |
| `可拼接剧情桥段.md` | 日常温情/户外冒险/反派冲突/搞笑趣味桥段 + 长线伏笔承接清单 |
| `场景奇遇灵感.md` | 22 目的地「景点+自然景观」整理为可入戏奇遇场景 |
| `分角色创意碎片.md` | 20 个角色各自专属人设剧情创意方向 |
| `文笔描写素材.md` | 拟声词/神态动作/角色对话风格/风物短句 |
| `外部参考灵感.md` | 《博物》《环球科学》《国家地理》中文版作幕后灵感（不点刊名）+ 民间童谣等 |
| `黑猫当当灵感全集.md` | 合并自两份灵感文档的 250+ 灵感合集（分龄/节日/节气/日常/配角/里程碑/奇幻/食物），🟢常州本地优先，已去蟹、去矛盾 |

## 创作调取逻辑
写新一集 → 从「主题立意库」选方向 → 从「可拼接剧情桥段/分角色创意碎片」取素材 → 回 `05-故事历史档案库` 核对设定防崩坏 → 从「02 场景/03 美食」取风物 → 落到教育点（听爸爸妈妈的话/保护宝宝）。

## 权威源
`series-dangdang-guide.md`（主题库/科普参考）、`dangdang-series-outline.md`（伏笔）、`dangdang-destinations.md`（场景）

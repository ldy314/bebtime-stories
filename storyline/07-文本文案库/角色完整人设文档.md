# 🐱 黑猫当当历险记 · 系列创作指南

> 本文件是「黑猫当当历险记」系列的**唯一创作事实来源**，由每周系列自动化读取。  
> 系列独立于每日睡前故事，一周生成一集（中文），不占用每日故事名额。

---

## 一、系列定位

- **系列名**：黑猫当当历险记
- **主角**：黑猫当当（黑色中华田园猫，公）
- **形式**：每周一集，中文，连载长篇轻冒险；与每日故事互不占用名额
- **总基调**：温暖、幽默、轻微冒险、强连续性、有明确教育意义
- **核心教育底线（每集至少体现其一，且自然融入）**：  
  听爸爸妈妈的话 · 保护家人 · 保护宝宝（家里最小最宝贝的成员） · 与兄弟姐妹/朋友互助 · 勇敢但知分寸 · 诚实 · 不挑食（对八百）

## 二、角色设定（固定，跨集连续）

### 当当（黑猫 · 中华田园猫 · 公）

- 外形：一身乌黑发亮短毛，金黄色眼睛，胸口有一小撮白毛（标记）。
- 性格：调皮、精力旺盛、能吃能喝能睡；在家喜欢「跑酷」（从沙发跳书架再滑下猫爬架，嗒嗒嗒、哧溜），还喜欢嗖地钻到床底下跟爸爸妈妈玩捉迷藏；最最爱爸爸妈妈摸他的下巴和肚皮，一摸就咕噜咕噜。
- 优点：勇敢、护家、讲义气、行动派。
- 缺点：有时太冲动、爱逞能、偶尔闯小祸。
- 成长线：从「小捣蛋」慢慢长成「负责任的守护者」，但调皮本性永远不变。

### 小不点（白猫 · 姐姐 · 母）

- 外形：通体雪白，粉鼻子，安静优雅。
- 性格：非常可爱、听话、乖巧；平时喜欢在院子里/小区慢慢散步，人见人爱，邻居都夸。
- 定位：家里的「小天使」+ 和事佬，常用温柔方式让当当冷静下来。
- 与当当：姐弟，互相爱护。

### 八百（狸花猫 · 哥哥 · 公）

- 外形：标准狸花斑纹（棕黑相间），体型壮实，慢吞吞。
- 性格：挑食（只吃某几种）、社恐（怕生人、怕吵、躲床底）、但极温顺，被摸会发呼噜。
- 定位：家里的「老好人」。
- 与当当：兄弟。当当崇拜又心疼哥哥，常想带八百「见世面」却被拒绝；八百在关键时刻会默默出手帮弟弟。

### 爸爸妈妈

- 故事的「安全基地」。爱三只猫，规矩清晰（如：不许抓沙发、出门要牵绳、听到名字要回家、保护好宝宝）。三只猫都要把保护宝宝当成最重要的任务之一——宝宝是家里最小、最宝贝的小成员。
- 教育落点主要通过爸爸妈妈的叮嘱 + 当当「听不听」来体现。

### 可联动的已有角色（来自每日故事宇宙，轻量客串）

- 棉棉（山谷小白兔）、小种子/小苗（春天破土）、小星星暖暖、风、月亮等。
- 联动要轻、自然，不抢主线。

## 二·A、全角色清单（家中常驻 / 偶尔出场邻居 / 反派）

### 家中常驻猫咪（补充提醒）

- **小不点 = 白猫姐姐**（长毛纯白、粉鼻子、浅湖蓝眼睛，走路轻得没有声音，脖子上常系一根当当给她做的浅粉小丝带）。性子软糯乖巧、从不抓家具，是家里的和事佬与温柔陪伴者。设定保持原样。
- **八百 = 狸花猫哥哥**（棕黑交错狸花斑纹、骨架宽大体型壮实、琥珀色圆眼、走路慢吞吞）。重度挑食（只吃水煮鱼肉、无盐鸡胸肉）+ 轻度社恐（怕生人、怕鞭炮汽车鸣笛，一受惊就钻床底衣柜），但极温顺，被摸会发出巨大呼噜；当当遇险时会克服恐惧默默挡在弟弟身前。设定保持原样。
- **重要命名约定**：本系列里「白猫姐姐」**专指小不点**。安徽定远那位白猫民俗探索家一律称 **卡莎**，不得再写作「白猫姐姐」，避免重名混淆。
- **故事发生地（家在江苏常州）**：当当一家住在**江苏常州**（长江三角洲、太湖之畔）。家是系列所有故事的安全基地与起点——做客单元发生在常州家里的客厅 / 院子 / 小区；外出旅游单元都从常州出发，再回到常州、回到宝宝身边。西太湖（青蛙小西的家乡）就在常州武进，是当当家门口的水上乐园，属本地邻居。

## 二·B、偶尔出场邻居角色（9 位 · 按剧情需要出场，不必每集到齐）

### 1. 青蛙小西｜西太湖水上小伙伴（已在 ep12《西太湖荷叶漂流》登场）

- 物种 / 居住地：翠绿小青蛙，住西太湖芦苇荡的泥洞。
- 外形：通体翠绿，雪白圆肚皮，头顶一道浅黄色细纹，后腿强健带蹼，游得飞快。
- 性格：自来熟话痨，一开口就呱呱呱说个不停，热心活泼；天生游泳健将，跳水、潜水、荷叶漂流样样精通。**特别怕热**——盛夏正午被太阳一晒就蔫巴巴趴着不动，只爱傍晚和夜里出门。
- 饮食：吃蚊子、苍蝇等害虫，是天然除虫小卫士；偶尔舔一口清甜的荷花蜜。
- 与当当：当当去西太湖玩时当水上向导，带他坐荷叶顺水漂流，讲水下小鱼、小虾、田螺的趣事；偶尔上岸做客，一晒到太阳就赖在凉席上不肯动弹。

### 2. 金毛大金毛｜楼上温顺狗狗哥哥（已在 ep18《大金毛的楼上派对》登场）

- 物种 / 居住地：金毛巡回犬，住当当家楼上。
- 外形：一身金灿灿顺滑长毛，尾巴像蓬松大扫把，圆溜溜的温柔杏眼，厚厚的肉垫爪子。
- 性格：极度温顺，从不吵闹、不欺负小动物，超级粘人爱蹭胳膊撒娇；作息规律，早中晚雷打不动下楼散步；爱捡树枝、叼小皮球，出门必带自己的蓝色小皮球，雨天趴窗边眼巴巴等天晴。
- 与当当：当当孤单时会上楼找他玩；散步全程守护，当当摔倒就用脑袋轻轻扶起；分享零食只小口轻咬从不争抢；听见当当开门的脚步声，早早趴在楼梯口摇尾巴等候。

### 3. 大狸花阿姨｜小区闲逛美食家（长辈）

- 物种 / 居住地：狸花猫长辈，没有固定房屋，在小区绿化带和各单元楼之间自由串门。
- 外形：棕黑相间条纹皮毛，粗长有力的尾巴，步伐优雅，耳朵灵敏，自带长辈稳重气场。
- 性格：小区八卦通，每天绕着花坛、草坪、车库巡逻；嗅觉格外灵敏，最大弱点是**嘴馋**，见着小鱼干小饼干就挪不动腿。做客时懂规矩会乖乖蹲在桌边，却总忍不住偷瞄餐盘、趁人不注意扒拉一口。吃饱爱趴窗台晒太阳，给当当讲小区里的趣事。
- 与当当：常上门蹭饭，当当吃饭得看牢自己的食物防偷袭；可当当受委屈、被欺负时，她会挺身而出保护当当，像位贴心长辈。（**已在 ep07《狸花阿姨来做客》首次登场**）

### 4. 野猪南南｜南京紫金山美食导游

- 物种 / 居住地：小野猪，住南京紫金山的山洞，和野猪大家族一起生活。
- 外形：棕褐色短硬皮毛，头顶一撮浅棕色软绒毛，小獠牙软软的不会伤人，四条长腿跑得飞快。
- 性格：精力充沛的爬山能手 + 十足旅行美食家，走遍各地挖掘特色小吃；热情大方，每次外出都收集特产打包寄给当当。熟记紫金山全部小路、野果树、隐秘小瀑布和观景台，是专属山林导游。唯一的小烦恼——总被修猴子捉弄，常追着他满山跑。
- 与当当：当当一家去南京时全程免费带队爬山、采野酸枣、看山间风景；定期邮寄桂花糕、雨花点心、山核桃。（**已在 ep08、ep09 登场**；ep10 以当当复述茅山经历时再次提及）

### 5. 修猴子｜茅山神秘修道小猴

- 物种 / 居住地：金丝小猴，道号修猴子，年龄未知，住茅山山顶道观旁的老桃树上。
- 外形：金红色柔软毛发，手脚纤细灵活，身披迷你青色小道袍，腰间挂一只装满鲜果的小布袋。
- 性格：随性神秘的小修道者，调皮爱恶作剧，最喜欢捉弄野猪南南（藏他的背包和美食，最后一定原样归还）；狂热水果爱好者，桃子、枇杷、野莓、荔枝全爱吃。
- **法术边界（重要）**：所会法术**全部温和无伤害**——让树叶在空中轻轻漂浮、变出彩虹、催开花朵、隔空传递果子、短暂隐身、召唤云朵代步。只用来制造快乐，绝不伤人。
- 与当当：偶遇便主动传授简单有趣的小法术（如轻轻飘叶）；关键时刻用法术化解反派的捣乱。（**已在 ep09《茅山遇修猴子》、ep19 登场**）

### 6. 小狗芒果｜沈阳东北摇滚小狗哥哥（已在 ep15《小狗芒果的摇滚连线》线上登场）

- 物种 / 居住地：小黄狗，名字芒果，住沈阳老胡同的小院。
- 外形：浅黄短毛，耷拉的软耳朵，脖子常年系一条红色摇滚小围巾，跑动时肚子一颠一颠。
- 性格：一口地道东北口音，天生搞笑乐天派，随口就是段子；口头禅「老弟、老妹、嘎嘎好玩、贼香」。资深摇滚爱好者，自制小木吉他和小鼓，常在自家小院办小型动物演唱会；冬天爱在结冰湖面滑冰、堆大雪人。
- 与当当：常和当当线上视频，分享东北雪景、冻梨、烤冷面；送过当当一把迷你木质小吉他，线上教他唱简单摇滚儿歌，每次都能把当当逗得开怀大笑；遇反派捣乱时用响亮叫声威慑。

### 7. 小狗钱包｜保定户外运动小狗哥哥（已在 ep13《小狗钱包回爸爸老家》登场）

- 物种 / 居住地：雪纳瑞（小黑狗），名字钱包，住保定郊外山野，离当当爸爸老家很近。
- 外形：乌黑发亮的短毛，修长有力的四肢，身材匀称结实，随身背一只迷你帆布小背包，里面装水壶和山野小零食。
- 性格：自律运动达人，晨跑、徒步、爬山雷打不动，精通露营踏青；熟悉山间野花野菜，清楚干净山泉和安全可食野果的位置，户外知识储备丰富；踏实稳重、细心靠谱，喜欢民谣和轻音乐，擅长发掘农家小吃。
- 与当当：当当回爸爸老家时带他进山徒步、认识花草，分享保定驴肉小点心，全程看护避免磕碰，闲时一起山间野餐听歌；**擅长追踪脚印**，能帮大家找回被反派偷走的东西。

### 8. 大象老友粉姐姐｜广西雨林旅行家（已在 ep11《广西遇老友粉》正式登场；**ep09 结尾由修猴子埋下伏笔**，ep10 以当当复述时再次提及）

- 物种 / 居住地：温柔小象，名字老友粉，住广西南宁，常年往返东南亚热带雨林。
- 外形：浅灰色细腻皮肤，宽大扇子状耳朵，柔软修长的长鼻子，挎一只装满各地小吃的编织大挎包。
- 性格：温柔大方、见识广阔，痴迷各地美食（广西米粉、热带水果、东南亚甜品），擅长识别雨林动植物，会讲雨林鹦鹉和小猴子的奇妙故事。长鼻子用处多多：摘高处的榴莲芒果、吸水浇花、卷起行李，还能给小伙伴按摩。
- 与当当：每次旅行结束都寄芒果、榴莲干、老友粉速食；讲热带雨林的新奇见闻，邀当当去广西吃粉逛雨林；**长鼻子能喷水、卷走反派藏起来的道具**，是对抗反派的得力帮手。（**ep09 结尾已埋下伏笔（ep10 复述）：「老友粉在广西等你们哦」**）

### 9. 卡莎｜安徽定远民俗探索家（已在 ep14《卡莎的定远庙会》登场）

> 该角色在原始设定文件中未定名，仅标注为安徽定远的一只白猫；**本系列正式定名为「卡莎」**，以免与家中的小不点（白猫姐姐）重名。

- 物种 / 居住地：通体雪白长毛白猫，住安徽定远——当当妈妈老家楼下的小院。
- 外形：纯白无杂色长毛，通透的蓝宝石双眼，爪子轻巧轻盈，身姿柔软。
- 性格：身手超凡，擅长飞檐走壁，房顶、墙头、大树都能轻松穿梭；常年在滁州、定远周边古镇老巷游历，是小小民俗专家，熟知本地传统小吃、老手艺、节日习俗；爱挖掘小众老街小店，收集民间小故事和手工小物件，每逢传统节日会提前备好特色点心。
- 与当当：当当回妈妈老家时，卡莎带他逛古镇、赶庙会，讲解剪纸、糍粑、花灯等民俗，还带他爬上屋顶俯瞰整片小镇；身法灵活，能悄悄跟踪反派、打探对方的坏主意。
- **命名规则（硬约束）**：正文中一律写「卡莎」，**禁止**写成「白猫姐姐」。

## 二·C、反派角色（低龄友好 · 无暴力 · 只偷窃 / 捣乱 / 恶作剧）

### 一只耳｜坏老鼠（已登场）

- 一身灰毛，右耳被咬掉一半故名一只耳；尖嘴巴、细尾巴，个子小小，动作溜得飞快，总背着一只破布小口袋。
- 贪嘴又贪心，鬼点子一堆，爱钻墙角、下水道、柜子缝隙；欺软怕硬，见到大金毛、八百、老友粉这种大块头立刻逃窜；偶尔和格格巫搭伙，偷来的零食两人平分。
- 弱点：怕猫（八百、小不点、狸花阿姨都能吓跑他）、怕强光、怕响亮的狗叫声；太贪吃，常常来不及逃跑被当场抓住。
- **当前状态**：ep01~ep06 已完成「伏笔—再现—收线」三拍；ep07、ep08 以**搞笑常客**身份回归（偷小鱼干、跟到紫金山偷特产，都被联手请走，没有受伤害）。后续可继续走搞笑常客路线，也可暂时缺席几集蓄力，**不必每集露脸**。

### 格格巫｜小巫师反派（已登场）

- 人类小个子巫师，住城郊偏僻的小黑木屋；头戴尖尖灰巫师帽，灰蓝色破旧长袍，尖尖鹰钩鼻，手里常年攥一只缺口魔法陶罐；**身边没有阿兹猫**（避免与猫咪角色冲突）。
- 魔法微弱，只会恶作剧药水，没有伤人魔法：迷雾药水（喷淡灰薄雾遮视线）、黏糊糊药水（粘住爪子和鞋子）、静音粉末（让小西的呱呱声、芒果的歌声暂时变小）、果树缩水药水（让果子和荷花暂时蔫掉）。
- 弱点：配药要草药和干果做材料，材料被抢就配不出来；害怕修猴子的正道小法术、怕老友粉的长鼻子喷水；心思急躁，很容易被小动物们联手拆穿。
- **当前状态**：ep06 首次登场即被喵喵歌与拉窗帘劝退；ep09（茅山遇修猴子）再度现身，在当当讲述的茅山故事里被修猴子变出的彩虹看呆了，忘了捣乱。**仍未真正收线**，随时可以卷土重来——建议下次升级伪装或引诱理由，让当当靠「不跟陌生人走」再赢一次。

## 二·D、跨国好友（波士顿 · Ruddy 一家 · 通过视频连线登场）

> 新角色来源：`增加角色.txt`（Ruddy 一家）。他们住在美国波士顿，是当当的跨国好朋友；**连接点：当当爸爸的母校是塔夫茨大学（Tufts University）**，Ruddy 一家常去校园打卡并视频分享给当当。

## 角色出场规则（每集谁必须出场、谁按需出场）

- **当当是每集必出的主角**：每集都以当当为核心视角展开，故事的行动线、情绪线都挂在当当身上。
- **其余角色按剧情需要出场**：小不点（姐姐）、八百（哥哥）、爸爸妈妈、宝宝、一只耳（坏老鼠）、格格巫等都是配角，**不要求每集全员到齐**，不必为了「凑人」硬安排戏份。
- **允许单角色小场景**：一集可以只聚焦「当当 + 1 个配角」——比如这集只和宝宝互动，或只和一只耳过招，甚至只在梦里和新角色相遇。人少反而节奏更自然、情绪更集中。
- **无论谁出场，都要服务两条主轴**：当集内容必须落在「连续性弧线」和「教育点」（听爸爸妈妈的话 / 保护宝宝）上。允许某集弱化甚至不写其他角色，但**主角当当的戏份与成长线不能断**。
- **反派跨集编排**：一只耳、格格巫按「伏笔 — 再现 — 收线」的节奏跨集安排，不必每集都正面登场；远远探个头、留个脚印、听见一声吱吱，都算有效的伏笔与再现。

8. **帮助别人**：帮迷路小鸟回家、帮邻居老奶奶捡毛线球、联动棉棉。
9. **邻居来做客**：狸花阿姨 / 大金毛 / 小西等邻居上门，美食分享 + 温柔陪伴 + 搞笑桥段，落点「分享」与「看好自己的东西」。
10. **地域旅行**：一家出门去南京、茅山、沈阳、保定、广西、安徽定远、西太湖，遇见当地邻居，自然带出各地风物民俗与自然知识，落点「跟紧爸爸妈妈」。
11. **奇妙朋友**：修猴子的温和小法术（飘叶 / 彩虹 / 唤云）等奇妙能力，落点「本事要用来制造快乐，不用来捣乱」。
12. **环球双语连线**：与 Ruddy 一家视频连线，认识波士顿山林、校园与英国 / 阿富汗 / 西班牙 / 墨西哥 / 越南等地的风物生态，双语（中 + 英）趣味点缀，落点「对世界保持好奇、和家人分享」。

> 每集结尾尽量回扣「听爸爸妈妈的话」——例如因听了叮嘱（牵绳/不爬高/跟紧），才化险为夷或玩得安全。

### 科普与地点参考来源（探险 / 旅行 / 古迹 / 自然类题材）

- 探险地点与科普知识点，可参考《博物》《环球科学》《国家地理》中文版的真实内容，作为**关键词与故事情节的灵感来源**：把真实的动物、植物、地貌、古迹、天文 / 海洋知识变成当当能懂的冒险背景，既好玩又有真料。
- 例：去山里 → 参考《博物》「中国常见山野动植物」；探古迹 → 参考《国家地理》「长城 / 石窟 / 古镇」专题；龙宫 / 海洋 → 参考《环球科学》海洋科普；看星星 → 参考《博物》天文栏目。
- **重要：这些杂志只当幕后灵感，故事正文与对外展示里都绝不出杂志名**（不写「据《博物》说」「《国家地理》上讲过」之类）。灵感悄悄融进情节即可，孩子读到的是当当的冒险，不是科普出处。
- 因此**不再填写、也不再展示 `source` 字段**（合集不再出现「📚 灵感来源」）。

## 四、连续性规则

- 角色性格与关系跨集不变；已发生大事记入 `dangdang-series-state.json` 的 `continuity`（一句话日志）。
- 允许长线伏笔：一只耳三次出现、当当跑酷越来越厉害、八百慢慢敢出门。
- 每集开头可用一两句「上集回顾」承接前情（从 state.continuity 取最近一条）。
- **年龄阶段随宝宝真实月龄推进**（同每日故事年龄映射，由日期算）：
  - 胎教期：爸爸妈妈讲给肚子里宝宝听的第三人称温柔叙事。
  - 0-1 岁：更短句、拟声更多。
  - 1-3 岁：加入当当简单对话。
  - 3-6 岁：完整冒险 + 对话 + 幽默。
  - 6 岁+：更深寓意。
- 每集必须自然融入「听爸爸妈妈的话」这一教育点（可显式可隐式，但孩子要听得出来）。

## 五、数据格式（写入 stories.json 的对象，额外字段）

通用字段同每日故事：`id / date / dateShort / title / language / ageGroup / ageLabel / preview / moral / content`。

额外字段：

- `series`: `"dangdang"`（固定，标记系列）
- `seriesTitle`: `"黑猫当当历险记"`
- `episode`: 整数（第几集，从 1 开始，连续）
- ~~`source`~~（已弃用）：早期曾用 `source` 记录科普灵感来源并在合集展示「📚 灵感来源」；现改为杂志只作幕后灵感、**不在故事与合集中出现杂志名**，该字段不再填写，生成器也不再渲染。

`id` 规则：`dangdang-ep{N}-zh`（N 两位补零，如 `dangdang-ep01-zh`）。`language` 固定 `"zh"`。

`title` 只填**故事名**（如「当当来我家」），不要自己写「第N集」——集数由 `episode` 字段统一展示：阅读器用「第N集」角标、合集用「第N集 · 故事名」前缀，生成器会自动加，避免重复。

弯引号禁用（同每日规范）：不用中文弯引号「"」，用「」或单引号。

## 六、风格参考

- 中文以**汤素兰（呆萌幽默）**、**孙敬修（口语亲切拟声）**、\*\*郑渊洁（调皮想象）\*\*为主；胎教期偏冰波/金波诗意。
- 轻松冒险风打底。
- 多用拟声词：当当跑酷「嗒嗒嗒、哧溜」；呼噜「咕噜咕噜」；蚊子「嗡嗡」。
- 每集 3-6 分钟，段落数组；`preview` 为前两句话；`moral` 为当集教育点（自然点出「听爸爸妈妈的话」或相关品质）。

## 七、每周生成机制（给自动化提示）

- **目标日**：每周六。若当天未运行（关机），下次运行时补生成「最近一个周六」的那一集（不补更早的）。
- 生成前读 `dangdang-series-state.json`：取 `episode`（下一集编号）、`continuity`（前情）、`arc`（当前故事线）、`linkages`。
- 生成后用 `apply_series_episode.py` 写入并更新 state（`episode+1`，追加 `continuity` 一句话，更新 `arc/linkages`）。
- **不占用每日故事名额**；每日检查遗漏时忽略带 `series` 字段的条目。

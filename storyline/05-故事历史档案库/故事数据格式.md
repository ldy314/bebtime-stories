# 故事数据格式（写入 stories.json 的对象）

> 来源：`series-dangdang-guide.md` 第五节。系列条目在通用字段基础上加 `series` 系列字段。

## 通用字段（同每日故事）
```json
{
  "id": "dangdang-ep01-zh",
  "date": "2026年7月25日 · 星期六",
  "dateShort": "07/25",
  "title": "当当来我家",
  "language": "zh",
  "ageGroup": "prenatal",
  "ageLabel": "胎教期",
  "preview": "故事前两句话……",
  "moral": "故事寓意（自然点出听爸爸妈妈的话/保护宝宝）",
  "content": ["段落1", "段落2"]
}
```

## 系列额外字段
- `series`: `"dangdang"`（固定，标记系列条目）
- `seriesTitle`: `"黑猫当当历险记"`
- `episode`: 整数（第几集，从 1 连续）

## 约束
- `id` 规则：`dangdang-ep{N}-zh`（N 两位补零）。`language` 固定 `"zh"`。
- `title` 只填故事名，不要写「第N集」——集数由 `episode` 字段统一展示。
- **弯引号禁用**：不用中文弯引号 `""`，用 `「」` 或单引号，否则 JSON 解析失败。
- `source` 字段已弃用（杂志只作幕后灵感，不在故事/合集出现刊名），不再填写、不再渲染。

## 自动写入
生成后用 `apply_series_episode.py` 写入 `stories.json` 并更新 `dangdang-series-state.json`（`episode+1`、追加 `continuity`、更新 `arc/linkages`）。
